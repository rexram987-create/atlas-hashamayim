# אטלס השמיים — מערכת השמש

אתר לימודי אינטראקטיבי בעברית על השמש ושמונת כוכבי הלכת במערכת השמש.

## תוכן האתר

- השם העברי והשם הלטיני של כל גוף
- אטימולוגיה מפורטת
- היסטוריית הגילוי והמחקר
- שם המגלה, או הבהרה כאשר הגוף מוכר מימי קדם
- תמונה מייצגת וקישור לדף הרישיון
- המרחק מכדור הארץ והסבר מדוע המרחק משתנה
- עיצוב רספונסיבי למחשב ולטלפון
- חלונות מידע אינטראקטיביים

## הפעלה מקומית

פתחו את הקובץ `index.html` בדפדפן. אין צורך בהתקנה או בתהליך בנייה.

## פרסום באמצעות GitHub Pages

המאגר כולל תהליך פרסום אוטומטי. בהגדרות המאגר יש לפתוח **Settings → Pages**, ולבחור ב־**GitHub Actions** כמקור הפרסום.

## מקורות

המידע מבוסס בעיקר על NASA, JPL, האיגוד האסטרונומי הבין־לאומי ומקורות אנציקלופדיים. התמונות נטענות מ־Wikimedia Commons, ובכל כרטיס קיים קישור לדף הקובץ ולפרטי הרישיון.
